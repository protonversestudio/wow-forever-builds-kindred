# Contributing

Thanks for the interest. This is a small fan project, so the bar is simple.

- Bug reports: open an issue with your Windows version and what you clicked.
- Build data: if a talent order or route step is wrong, an issue with the correct data is enough.
- Code: keep the change small and described. The project builds with Go 1.22+ (`go build ./src`).

By contributing you agree your contribution is MIT-licensed. Blizzard assets are not accepted as contributions.
